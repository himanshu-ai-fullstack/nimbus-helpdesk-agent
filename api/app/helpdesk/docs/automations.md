# Automations and run limits

Automations run actions when something happens in a project, for example "when a task moves to Done, notify the channel".

Each time an automation's action runs, it uses one automation run. Pro includes 250 runs per month and Business includes 2,000. Runs reset on the first day of each billing month. When you hit the limit, automations pause until the reset, or you can buy extra run packs of 1,000 runs for $10 from **Settings > Billing > Add-ons**. Consumed run packs are not refundable.

If an automation is not firing, check that it is turned on, that the trigger project is correct, and that you have runs left this month.

# Returns and refunds

You can return delivered items within **30 days of delivery** for a refund to your original payment method. Items should be unused, or defective.

## How it works
1. Ask our support assistant or visit **Orders > Return an item**.
2. Our team approves the return and emails a prepaid return label.
3. Refunds are issued when the return is approved and take 5 to 7 business days to appear.

## Limits
- Orders that haven't been delivered yet can't be returned. If the order is still processing, cancel it instead.
- Support can approve return refunds up to $200 per request. Larger refunds are reviewed by our returns team.
- Returns after 30 days are not accepted, except for defects covered by the warranty.

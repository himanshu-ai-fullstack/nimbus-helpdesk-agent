# Phishing and security incidents

If you clicked a suspicious link or entered your password on a page you don't trust:

1. Change your Okta password immediately from a device you trust.
2. Don't forward the email to colleagues. Use **Report phishing** in Gmail.
3. Tell the helpdesk right away so the security team can check your account.

Lost or stolen devices, suspected malware and any accidental sharing of confidential data are also security incidents and are handled urgently, around the clock.

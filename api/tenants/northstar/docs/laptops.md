# Laptop policy and replacements

Every employee gets one laptop: a MacBook Pro for design and engineering, a ThinkPad for other teams. Laptops are refreshed after four years.

If your laptop is damaged (cracked screen, liquid spill, failing battery) or end of life, IT replaces it. Ask the helpdesk to request a replacement; IT approves it and ships a new machine within 3 business days. Back up anything not in Google Drive first.

A **lost or stolen** laptop is a security incident: report it immediately so IT can lock and wipe it.
